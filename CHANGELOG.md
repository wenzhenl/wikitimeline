## 1.0.0 (2025-03-04)

Major release of WikiTimeline with significant improvements to timeline quality, user experience, and multilingual support.

### Timeline Content Improvements
- Overhauled timeline quality with more comprehensive event lists and detailed descriptions
- Enhanced handling of long articles (e.g., "History of United States") through multi-round processing to overcome token limits
- Improved parsing of Wikipedia tables (e.g., "List of United States Presidents")
- Added age information for biographical timelines

### User Experience Enhancements
- Added customizable navigation bar height
- Implemented event filtering based on start/end dates and importance
- Significantly improved scrolling for easier timeline navigation
- Enhanced search with better autocomplete experience

### Multilingual Support
- Added support for all languages with 1M+ Wikipedia articles
- Implemented cross-language timeline comparison functionality

## 0.1.0 (2025-02-01)

Initial version of WikiTimeline open sourced which uses Gemini to summarize the major events from Wikipedia articles.
